## 🚀 Featured project: AleyNode

I'm building **AleyNode**, a self-hosted cryptocurrency market-intelligence platform for **spot portfolio monitoring** and **short-horizon futures analysis**.

AleyNode currently combines:

- Live market and derivatives data from **Binance, Bybit, OKX and Coinbase**
- Multi-timeframe technical and market-structure analysis
- Spot portfolio monitoring through **Portfolio Guardian**
- Futures microstructure, taker flow, open interest, funding and positioning
- Per-component freshness, quality checks and stale-data detection
- A **Python / FastAPI** backend split into market and admin services
- **Raspberry Pi + Linux + systemd** production infrastructure
- **Cloudflare Tunnel / Access** for protected remote APIs
- Git and GitHub-based development, validation and recovery workflows
- AI-assisted analysis with a deliberate separation between data, reasoning and real-money decisions

The design principle is simple:

> **Data layer → analysis layer → human decision**

AleyNode does not autonomously place trades. The backend provides structured evidence; the analyst reasons over it; the user remains the final authority for real-money actions.

## 🧱 What I care about

I prefer systems that are not only feature-rich, but also:

- **Reliable** — failures should be visible and bounded
- **Observable** — freshness, health and degraded components should be explicit
- **Recoverable** — operational access should survive service restarts and development mistakes
- **Maintainable** — clear process boundaries, modular integrations and versioned changes
- **Safe by design** — secrets stay out of repositories and privileged operations stay narrowly scoped
